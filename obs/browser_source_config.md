# Browser Source Configuration

Use this page as a browser source in OBS.

## Steps

1. Start the frontend app.
2. Open the dashboard or 3D scene URL.
3. In OBS, add a Browser Source.
4. Paste the URL and set width/height to 1920x1080.

## URL example

```text
http://localhost:3000
```

## Notes

- Use a transparent background when needed.
- Enable `Shutdown source when not visible` to reduce GPU usage.
- For a dedicated stream view, set `Refresh browser when scene becomes active`.
